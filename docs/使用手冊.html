1這是什麼

一分鐘認識這套工具

「社團帳本」是一套安裝在自己電腦上使用的記帳程式，專為社團、系學會、球隊等 需要管理公款的團體設計。所有資料都存在自己的電腦裡，不需要連網也能記帳、 看報表，交接給下一屆也只要把一個備份檔交出去即可。

💰

收支記帳

一筆一筆記錄收入與支出，自動結算結餘

📊

報表與預算

依專案/活動、部門自動彙總，掌握花費狀況

👥

多人共用

可建立多組帳號，依角色開放不同的操作權限

🗂️

交接方便

一鍵匯出備份檔，下一屆接手不必重新輸入資料

2安裝與開啟程式

不需要安裝精靈，拿到程式就能用

  1. 取得程式檔案：通常會拿到一個檔名類似 ClubLedger.exe 的執行檔（也可能連同一份出版圖示檔或說明文件一起收到）。把它放到一個你自己好記得的資料夾即可，例如「文件 / 社團帳本」，不需要特別安裝到某個系統資料夾。
  2. 直接雙擊開啟：第一次執行會開出一個新視窗，就是整個程式的畫面。
  3. 如果 Windows 跳出「您的電腦受到保護」的藍色警告視窗：這是 Windows SmartScreen 的提醒，因為這個程式沒有購買昂貴的商用簽章憑證，不代表檔案有問題。點一下視窗裡的「其他資訊」，再點「仍要執行」即可正常開啟。
  4. 如果防毒軟體跳出警示或直接刪除/隔離了這個檔案：這也是常見的「未知發行者」誤判，不是真的中毒。可以到防毒軟體的「隔離區/威脅記錄」把檔案還原，或在防毒設定裡把這個檔案加入白名單/排除清單後再重新開啟一次。
💡
可以放心把 EXE 搬到別的資料夾或改檔名 你記錄的帳本資料並不是存在這個 EXE 檔案裡，而是另外存在 Windows 自己的使用者資料夾裡，所以就算你把 EXE 搬家、改名字、甚至重新下載一份新的 EXE 蓋過去，裡面已經記錄的帳本資料都不會不見。
⚠️
電腦上需要有 Microsoft Edge WebView2 元件 這是 Windows 10/11 用來顯示程式畫面的內建元件，一般電腦都已經有了。如果雙擊 EXE 後完全沒有反應，或只開出一個空白視窗，代表這台電腦缺少這個元件，請搜尋「WebView2 Runtime 下載」安裝（微軟官方免費提供），安裝完再重新開啟一次程式即可。

3第一次使用

建立你的第一本帳本

示意畫面・選擇帳本
帳
選擇帳本
一台電腦可以管理多個社團的帳本
＋ 新增帳本並進入
  1. 第一次開啟時會看到「選擇帳本」畫面（目前還沒有任何帳本），在欄位輸入帳本名稱（例如「吉他社」），按下「＋ 新增帳本並進入」。
  2. 接著會進入「建立社團帳本」設定精靈，填寫：社團名稱、喜歡的主題顏色、管理員姓名、登入帳號（之後登入要用，建議英數字，自己容易記得）、密碼（至少4碼）。
  3. 「帳本啟用信箱」欄位為選填，如果你的社團是由某位系統管理者/發行者統一管理多個社團，請依對方指示填寫這個欄位；如果不確定，先留空，之後仍可以在「系統設定」補填。
  4. 按下「建立帳本」，就會直接用剛剛設定的管理員帳號登入，進入主畫面。
🔒
密碼請自己保管好 密碼只會存在這台電腦本機裡，沒有「忘記密碼用信箱找回」這種雲端機制。請見本手冊「常見問題」裡「忘記密碼怎麼辦」一節，並養成習慣：至少設定兩組管理員帳號，互相備援。

5日常操作

最常用到的幾件事

📝 新增一筆收支

  1. 點「記帳」頁籤 →「＋ 新增一筆」。
  2. 填入日期、類型（收入／支出）、金額、分類、對應的專案或部門（若有）、經手人、備註等。
  3. 存檔後會立即反映在儀表板與報表的加總裡。

🧾 批次核銷／請款

如果有多筆代墊款項需要一次請款結算，可在記帳列表勾選多筆項目後，使用批次結算功能一次處理，不用一筆一筆手動改狀態。

🗂️ 建立專案/活動、部門、分類、經手人

到「管理中心」頁籤分別維護：

  • 專案/活動：例如「迎新茶會」「期末成果展」，可依學期分別建立，方便單獨看這個活動的收支與結餘。
  • 部門/組別：例如「公關組」「器材組」，可設定各自的預算額度。
  • 帳目分類：例如「交通費」「餐飲費」「場地費」，全社團共用同一份清單。
  • 經手人：實際經手金錢的人（代墊、收款），只是一個名字標記，不需要是系統登入帳號。

📤 匯出 CSV / 列印報表

記帳列表與報表頁都提供匯出 CSV（可用 Excel 開啟）與直接列印的功能，方便製作成冊存查或提交給社團指導老師、系學會審核。

🖋️ 上傳簽章與社團章

在「系統設定 → 簽章與社團章」可以上傳經手人簽名或社團大小章的圖檔，之後列印報表時能自動蓋在對應位置，不用印出來再手動蓋章簽名。

🗓️ 學期管理

可以建立多個學期（例如「113學年度上學期」），切換「檢視學期」後，專案/活動、部門預算等畫面只會顯示該學期範圍的資料，方便每學期各自結算、互不混淆。

6帳號與權限（管理員操作）

在「系統設定 → 帳號與權限」子頁進行，僅管理員角色可見

角色可以做什麼
管理員所有功能皆可操作，包含新增/刪除帳號、重設密碼、修改角色
會計可處理日常記帳、報表、預算、系統設定中的一般設定，但無法新增/刪除他人帳號
一般成員依管理員指派的頁籤權限使用，通常用於唯讀查詢或單純記帳

👤 新增一位成員

  1. 系統設定 → 帳號與權限 →「＋ 新增帳號」。
  2. 填寫姓名、登入帳號、初始密碼、角色，以及要開放的頁籤。
  3. 把登入帳號與初始密碼告訴對方，請對方自行登入後盡快更改成只有自己知道的密碼。

🔑 幫別人重設密碼

某位成員忘記密碼時，管理員可以到「帳號與權限」找到該帳號，執行重設密碼，系統會產生一組臨時密碼，請把這組臨時密碼告訴對方；對方用這組臨時密碼登入後，會被要求立刻設定一組新密碼才能繼續使用，管理員不需要也不會知道對方最後設定的新密碼。

7備份與還原

這是整本手冊裡最重要的一節，請務必養成習慣

⚠️
所有資料只存在這台電腦裡，沒有雲端備份 電腦故障、重灌、檔案誤刪都可能造成資料遺失，定期手動備份是唯一的保險，強烈建議每次記完一批帳，或每週/每次重大異動後，養成隨手備份一次的習慣。

📥 匯出備份檔

  1. 系統設定 →「備份與還原」→「匯出備份檔」。
  2. 跳出存檔視窗後，選擇要存放的位置（建議另外存一份到隨身碟、雲端硬碟或 email 給自己），檔名預設會包含帳本名稱。
  3. 產生的是一個 .json 檔，請完整保留這個檔案，不要用文字編輯器手動修改內容。

📤 還原備份檔

  1. 系統設定 →「備份與還原」→「匯入備份檔」。
  2. 選擇「合併」或「完全取代」：
    • 合併：保留目前帳本既有的資料，備份檔裡的內容會疊加/覆蓋同名項目，適合「補回遺漏的一部分資料」。
    • 完全取代：會先清空目前帳本的「所有」資料，再換成備份檔內容，適合「整本帳本換成另一個時間點的狀態」或「交接給新接手的人」，此操作無法復原，請務必先確認檔案沒選錯。
  3. 選擇備份檔並確認後，畫面會顯示已還原的資料筆數，並自動重新整理，之後請用備份檔裡原本的帳號密碼登入。
💡
建議的備份習慣
  • 每次完成一批記帳作業後，順手匯出一次
  • 每學期結束、交接前，務必匯出一份並妥善保存
  • 要測試「完全取代」或還不熟悉的功能前，先匯出一份當下的備份，有狀況隨時能還原

8多帳本管理

一台電腦可以同時管理好幾個社團

如果你同時要經手不只一個社團的帳目，不需要安裝多次程式。開啟程式時的「選擇帳本」畫面可以：

  • 新增帳本：建立另一本完全獨立的帳本，彼此資料不互通。
  • 設為預設：設定後，下次開啟程式會直接跳過選擇畫面，進入該帳本的登入頁；要切換回其他帳本，可在程式內「系統設定」或畫面角落的切換帳本功能回到選擇畫面。
  • 刪除帳本：會永久刪除該帳本所有資料，此操作無法復原，刪除前請先確認已匯出備份。

9換電腦 / 交接給下一位

畢業季、交接典禮前最實用的一節

  1. 在舊電腦／卸任前，到「系統設定 → 備份與還原」匯出一份最新的備份檔，連同程式 EXE 一起交給接手的人（例如用隨身碟拷貝，或雲端硬碟傳送）。
  2. 對方拿到 EXE 後，依本手冊「第一次使用」的步驟開啟程式、新增一本帳本，建立設定精靈時先隨意填一組暫時的管理員帳號密碼即可（這組暫時帳密之後會被備份檔內容整個取代）。
  3. 用這組暫時帳號登入後，到「系統設定 → 備份與還原 → 匯入備份檔」，選擇「完全取代」模式，選取你交給他的那份備份檔。
  4. 還原完成、畫面自動重新整理後，登入畫面就會變成原本帳本裡真實的帳號清單，請接手的人直接用你原本設定的帳號密碼登入即可，不需要重新設定密碼。
💡
搬家前別忘了：如果你的電腦上同時管理好幾個社團的帳本，請針對要交接的那一本個別匯出，其餘帳本不受影響。

10常見問題 Q&A

Q：雙擊程式沒有反應，或只跳出一個空白視窗？

通常是這台電腦缺少 Microsoft Edge WebView2 元件，請搜尋「WebView2 Runtime 下載」安裝後再試一次（見第2節「安裝與開啟程式」）。

Q：忘記自己的登入密碼怎麼辦？

請找同一本帳本裡其他的管理員，請對方到「系統設定 → 帳號與權限」幫你重設密碼（見第6節）。如果整本帳本所有管理員帳號都忘記密碼或已被誤刪，一般使用者無法自行解鎖，請聯繫原本協助建置這套系統的人員（系統管理者/發行者），由對方到這台電腦上協助處理救援；處理前建議先匯出目前能存取的任何備份資料。

Q：開啟程式顯示「此帳本尚未啟用」或「試用期已結束」？

代表這本帳本有設定遠端啟用管制、但尚未完成登記或已被標記為停用，請依畫面指示聯繫你的系統管理者/發行者確認啟用狀態，不需要自己動手修改任何設定，對方確認後重新整理畫面即可恢復使用。

Q：操作到一半畫面突然要求重新輸入密碼？

這是程式的自動鎖定保護機制：閒置超過10分鐘沒有任何操作，會自動回到登入畫面，重新輸入密碼即可繼續，資料不會遺失。

Q：之前建立的帳本在「選擇帳本」畫面不見了？

請確認是不是換了一台電腦、或重灌/清除了使用者資料（帳本資料存在電腦的使用者設定檔資料夾裡，不在程式本身的資料夾裡，見第9節「換電腦/交接」的說明）。如果只是想找回備份，請用先前匯出的備份檔、依「還原備份檔」步驟在新建立的帳本裡還原回來。

Q：誤刪了一筆交易記錄，可以復原嗎？

記帳資料的刪除目前沒有「資源回收桶」、無法單筆復原，如果有定期備份，可以用最近一次備份還原回來（但會連同備份之後新增的其他資料一起回到備份當時的狀態），這也是為什麼建議養成定期備份習慣的原因。

Q：想要把資料印出來蓋章用，格式跑掉怎麼辦？

請改用程式內建的「列印」功能（而不是把畫面截圖列印），已針對紙張邊界做過調整；如果印表機驅動程式另外加上了自己的頁首頁尾，可到印表機的列印設定裡關閉「頁首及頁尾」選項。

11注意事項

🔁

定期備份

這是避免資料遺失唯一的保險，請務必養成習慣（見第7節）

🔐

密碼各自保管

每人使用自己的帳號登入，不要共用同一組帳密，方便追蹤誰異動了什麼

🚫

不要手動改動資料檔

不要用其他軟體直接開啟/編輯程式存放資料的檔案，可能導致資料損毀

🧑‍🤝‍🧑

角色分級使用

依實際需要的操作範圍指派角色與頁籤權限，而不是每個人都開管理員

💾

完全取代要小心

還原備份選「完全取代」會清空現有資料且無法復原，動手前再三確認檔案

📬

有問題找系統管理者

遇到啟用狀態、功能權限等訊息，聯繫協助建置系統的人員處理最快
